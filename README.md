## Why most Kendra Scott coupon codes you find won't work

Most listing pages fail on basic reliability, and the codes themselves often aren't what they appear to be.

Start with the listings. Another tracker added 44 "new" Kendra Scott codes in 30 days, with a typical code lifespan of about a month — which mostly means the sites are churning through each other's expired inventory.

Then there's the fine print on the codes themselves. A large share of current Kendra Scott codes floating around social media carry the GIVEBACK prefix, and the wording matters: several of these are "20% of your purchase will be donated" codes tied to Instagram and TikTok fundraisers, not 20% off your order. If you skim a listing and see "20%" next to a GIVEBACK code, read the description before you expect a discount. Some GIVEBACK codes are genuine 20% off offers, some are donation codes, and some are locked to specific dates (a couple tracked recently only worked on two named days in November).

1. **Preorder items reject all codes.** Kendra Scott's own FAQ states that discount codes and gift cards cannot be used on preorder items. If that new collection is available for preorder, nothing applies to it.
2. **One promo code per order.** Kendra Scott generally allows a single code per order. Automatic perks like the free shipping threshold usually apply alongside a code, but a second code won't stack.
3. **Some codes require an Insider login.** Certain promotions only work if you're signed in to a free Kendra Scott Insider account, which most coupon pages never mention.
